# ФинишАрт

Статично копие на [finishart.bg](https://www.finishart.bg/) за хостинг на Cloudflare Workers. Съдържанието следва публичния сайт към 25.10.2026. Домейнът не се прехвърля от този проект.

## Локално

```bash
python render_site.py
npx wrangler dev
```

Страниците са на `/bg` и `/en`. Без Worker формата не изпраща поща, а `/` не пренасочва според езиковата бисквитка. За преглед само на страниците:

```bash
python -m http.server 3010 --directory public
```

`public/index.html` праща статичния преглед към `/bg`. В Worker-а `/` е 302 към `/bg` или към `/en`, ако посетителят вече е избрал език.

## Форма за запитване

`POST /api/contact` валидира имейл и текст, има honeypot и ограничение до едно изпращане на минута от IP. Пощата минава през [Resend](https://resend.com/).

Копирайте `.dev.vars.example` в `.dev.vars` и попълнете:

- `RESEND_API_KEY`
- `CONTACT_FROM` — потвърден подател в Resend, например `FinishArt <hello@finishart.bg>`
- `CONTACT_TO` — по подразбиране `alex.finishart@gmail.com`

За производство същите стойности се задават като секрети:

```bash
npx wrangler secret put RESEND_API_KEY
npx wrangler secret put CONTACT_FROM
```

Без тези стойности формата връща грешка и подканва към телефона.

## Какво е запазено нарочно

- Заглавия с `| Alex` на портфолиото и правните страници.
- Текстът „прецизност до посления детайл“ и „Финиш Арт представя демонстрира…“.
- Началната цена „8–22 евро/кв.м“ и PDF лукс офертата до 25 €/кв.м са различни в оригинала и не са изравнени.
- Колекцията „Други обекти“ включва офис пространството (май 2025) и реновацията на стълбище (януари 2026), както са на оригиналния Wix сайт.
